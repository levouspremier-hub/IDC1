## 1. 目标

M5.2c 退役了 `values[T+1]` API 并改为逐 transition 的
`(current_values[T], next_values[T])`。`train.py` 仍构造 `T+1` 数组、并只从
buffer **最后一条** `next_observation` 取 bootstrap，因此当前 HEAD 为红：

```
safe_rl_v2/train.py:126: error: Missing positional argument "next_values" in call to
"compute_three_value_targets"  [call-arg]
```

本卡把该调用点改为对 **observation batch** 与 **next_observation batch** 分别前向，
逐条取得各自的 critic 估计。**不新增 RL 数学**：不引入 PPO ratio/clip、熵项或乘子新语义。

## 3. 禁止项

1. **不得**再构造 `T+1` 长度 values，或「只读最后一条 `next_observation`」。
2. **不得**引入 PPO ratio/clip、熵项或新的乘子语义。
3. **不得**让 `exec_action` 进入任何概率或 target 计算。
4. **不得**以 dry-run 更新或损失数值宣称训练有效、收敛或性能改善。
5. **不得**改动 M5.2c 的数学语义或 `models.py` 的任何行为。

## 4. 实现要求

1. 从 buffer 分别形成：
   - `obs_batch` = 全部 `transition.observation`；
   - `next_obs_batch` = 全部 `transition.next_observation`；
   - `terminated` / `truncated` 逐条布尔掩码。
2. critic 对**两个 batch 分别前向**，得到每头的 `current_values[T]` 与 `next_values[T]`。
3. 调用 M5.2c 的唯一 API：
   `compute_three_value_targets(rewards, business, carbon, current_values, next_values,
   terminated=, truncated=, gamma=, lam=)`。
4. actor likelihood 仍只对 `raw_actions`（`evaluate_raw_actions`）；
   `exec_action` 不进入任何概率或 target。
5. 返回指标的 bootstrap 溯源改为
   `"buffer_transition_next_observations"`，**不得**再称
   `"buffer_last_next_observation"`。
6. 保留单位约定：业务违规量 = 「违规任务·步」，碳 = kgCO2e，电费 = SGD，三者独立。
7. 保留 `bootstrap_is_terminal`（M5.1c 既有断言依赖它）。

### 4.1 `bootstrap` 指标新形态

```python
"bootstrap": {
    "source": "buffer_transition_next_observations",
    "terminated_count": int,      # 该 buffer 内 terminated 的步数
    "truncated_count": int,       # truncated 的步数
    "bootstrapped_count": int,    # 实际使用本条 next_value 的步数 = (~terminated).sum()
}
```

## 7. 关键接线测试（必须使用 monkeypatch collector）

用 monkeypatch 替换 `collect_rollout`，构造一个**两 episode** buffer：

- `t=0` 为 `truncated`；
- `t=1` 属于下一条 episode；
- `t=0` 的 `next_observation` 与 `t=1` 的 `observation` **故意不同**。

必须证明：

1. 传给 target API 的 `next_values[0]` 来自 `t=0.next_observation` 的 critic 估计
   （与独立前向重算一致），而**不是** `t=1.observation` 的；
2. 改动 `t=1.observation` 的 critic 值**不得**污染 `t=0` 的 truncated bootstrap。
