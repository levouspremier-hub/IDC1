## 1. 目标

M5.3a 建好了独立、带单位、可恢复的乘子状态，但 `train.py` **完全没使用**它们：
actor 项仍是 `-(A_reward * log_probs).mean()`，乘子只在最后被更新一次。
本卡把乘子接入 actor objective，使约束以**独立**的代价项进入策略梯度。

**不新增 PPO 数学**：不实现 ratio/clip、不引入熵项。

## 3. 禁止项

1. **不实现** PPO ratio/clip 或熵项。
2. **不得**对 `exec_action` 求概率或把它放进任何 target / objective。
3. **不得**让电费（SGD）或未来真值进入 actor objective 或乘子更新。
4. **不得**用一个共享乘子；business 与 carbon 必须各自独立。
5. **不得**以 dry-run 损失数值宣称训练有效、收敛或性能改善。
6. **不得**改动 M5.3a 的乘子数学或持久化 schema。

## 4. 实现要求

1. **有效优势**（唯一形式）：

   ```
   A_eff[t] = A_reward[t] − λ_business * A_business[t] − λ_carbon * A_carbon[t]
   actor_loss = −mean(A_eff * log_prob_raw)
   ```

   `log_prob_raw` 仍由 `policy.evaluate_raw_actions(buffer.observation, buffer.raw_action)`
   计算；**绝不**对 `exec_action` 求概率。

2. **时序**：本轮 actor loss 使用**更新前**的乘子；
   `optimizer.step()` **之后**才用当前 rollout 的每 transition mean 更新乘子
   （`lagrangian.update({"business": <per-transition 序列>, "carbon": ...})`）。

3. **返回指标**（全部标注为 dry-run 诊断）：

   | 字段 | 含义 |
   |---|---|
   | `multipliers_pre_update` | 本轮 actor 目标实际使用的乘子 |
   | `multipliers_post_update` | 更新后的乘子 |
   | `multipliers` | 既有键，等于 post-update（保持 M5.1c/M5.4 语义） |
   | `constraint_means` | 各约束本轮 rollout 的每 transition mean（含单位） |
   | `constraint_budgets` / `constraint_units` | 各约束预算与单位 |
   | `effective_advantage` | `mean/std/min/max` + `formula` + `multipliers_used="pre_update"` |
   | `effective_advantage_terms` | `reward_mean` / `business_mean` / `carbon_mean` 三项分解 |
   | `actor_objective_source` | 固定字符串，标注使用的是上述公式 |

4. **独立性**：`λ_business = 0` 时 business 项恒为 0，且**改 `λ_carbon` 不得改变**
   reward 项与 business 项；反之亦然。
