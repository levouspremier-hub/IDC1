# M6.CAMPUS_GIT_BUNDLE — 固定提交的校园 SSH 来源交付

- 边界：本卡、开发报告、runs/m6_campus_git_bundle_*操作证据；本地Git bundle与主机独立bundle mirror，既有idc_remote submit/worker/collect接口。仅对新worker进程注入Git URL rewrite环境，将项目GitHub URL映射到已SHA验签的本机file mirror；不写全局或仓库持久设置、不改科学源码或idc_remote代码。
- 禁止项：不修改代理/防火墙/无关网络设置，不关闭TLS校验，不修改远端源项目origin，不重启失败job，不覆盖v27候选/旧证据、不跳候选/输入/checkpoint验签，不增加正式512授权。失败完整回传，不以submitted/PID表示正在运行。
- 验收命令：开卡status/branch/HEAD/diff-check；保留首次v27任务failed终态/console/receipt；Git bundle verify、两端bundle SHA、镜像commit SHA与git fsck，git show固定提交候选SHA；以每次进程GIT_CONFIG_* URL rewrite提交新job，既有worker仍按固定SHA fetch/worktree、uv --frozen及原SHA输入回执执行；状态/锁实查、终态全回传/验签。
- 证据产物：标准五类runs、bundle源/目标SHA与大小、基准commit、实际sent/received字节、每次进程环境覆盖范围、原origin未变证据、request argv/源码SHA/候选SHA/真实终态。运行中仅摘要，完整日志终态回传。
- 回滚点：分支p5-eval-viz-m6-p2c-root-numerics，db3fee5；显式add/独立git revert；临时URL rewrite仅随worker进程存活，不产生永久配置。保留bundle/mirror及失败现场，不删除原共享repo。

根因：首次runtime-v27-governance-campaign-20261011-v1在准备阶段exit未产生训练退出码，Git fetch返回128。console明确Failed to connect github.com port443 via127.0.0.1；既有本机代理端点不可达。没有科学诊断或PPO执行，不计为冻结候选长准入数值失败。采用固定源bundle只改变来源交付路径，科学来源、依赖、输入和放行规则保持；通过独立镜像和每个进程环境，避免修改用户原GitHub origin或全局代理。
