### 7.4 512 批 / seed × 3 seed 外推

```text
per_seed = per_batch × 512 ；all_seeds = per_seed × 3
per_batch = 批内墙钟(实测) + 批次边界 checkpoint 写入(实测)
典型 = 稳定批 p50 35.63 s ；保守 = 稳定批 p95 36.78 s
```

| 量 | 典型 | 保守 |
|---|---|---|
| 每批 | 35.63 s | 36.78 s |
| **每 seed（512 批）** | **5.07 h** | **5.23 h** |
| **全部 3 seed** | **15.20 h** | **15.69 h** |
| transitions / seed | 98 304 | 同 |
| transitions 合计 | 294 912 | 同 |

**磁盘**：每个 checkpoint 850 533 B；按**每批都保存**的上界，3 seed 合计 **1.22 GiB**
（每 seed ≈ 0.41 GiB），与批数成线性。
**内存**：峰值 0.50 GiB / 机器 16 GiB（3.1%）——内存不是约束。

**未包含的时间**：首次初始化一次性成本（未单独隔离）；最终 policy 导出与评估；
validation/test；**其他四类方法**（未实现、未测）；数据下载 / 环境安装 / 依赖解析。

### 7.5 建议

**本机运行（无需外移）**——依据：9 批实测稳定成本 p50/p95 = 35.63 / 36.78 s，
512 批 × 3 seed ≈ **15.2–15.7 h 连续运行**；峰值内存 0.50 GiB（3%）；磁盘上界 1.22 GiB。
**限制**：本卡**未**获得可用工时上限，故**不**判定能否在某截止期内完成，
**不自造通过门槛**；上述为**连续**时间，重启/休眠/并发都会延长；
四类方法未测，五方法总预算**不能**由本卡相加得出。
