## 1. 缺陷（M5.2a 引入）

M5.2a 的 API 接收长度 `T+1` 的 `values`，并用 `values[t+1]` 作为第 `t` 步的 bootstrap。
这对**单 episode、末尾 bootstrap** 的 rollout 恰好成立（`obs[t+1] == next_obs[t]`），
但对**中间 truncated** 或**多 episode** buffer 是错的：此时 `obs[t+1]` 属于**下一条
episode**，`values[t+1]` 是它的 value，而第 `t` 步真正需要的 bootstrap 是
`V(next_observation[t])`。**该 API 根本无法表达这两者不等的情形。**

### 1.1 最小反例（实测，`gamma=lam=0.5`）

```python
signal         = [1.0, 1.0]
current_values = [0.0, 0.0]      # V(obs[0]), V(obs[1])
next_values    = [10.0, 0.0]     # V(next_obs[0]) = 10  !=  V(obs[1]) = 0   <-- 关键
terminated     = [False, False]
truncated      = [True, False]   # t=0 截断，t=1 属于下一条 episode
```

正确语义：`t=0` 的 delta `= 1 + 0.5*10 - 0 = 6` → `target = [6.0, 1.0]`。
旧 API 实测输出 `target = [1.0, 1.0]`（`t=0` 误用 `values[1] = V(obs[1]) = 0`），
**误差 5.0**。

**不得以「collector 当前只存一条 episode」为理由保留该 API**——语义错误不会因为
当前调用方的巧合而消失，且 M5.4 的跨 episode 恢复会直接踩中。

## 4. 新 API 语义

```python
compute_signal_gae(
    signal,            # (T,)
    current_values,    # (T,) 对应每条 observation
    next_values,       # (T,) 对应**同一条 transition** 的 next_observation
    *, terminated, truncated, gamma, lam,
) -> (advantage, target)

compute_three_value_targets(
    rewards, business_violations, carbon_emissions,
    current_values={"reward": (T,), "business": (T,), "carbon": (T,)},
    next_values={"reward": (T,), "business": (T,), "carbon": (T,)},
    *, terminated, truncated, gamma, lam,
) -> {"reward": (adv, tgt), "business": (adv, tgt), "carbon": (adv, tgt)}
```

递推（反向，t = T-1 … 0）：

```
bootstrap[t] = not terminated[t]
carry[t]     = not terminated[t] and not truncated[t]

delta[t] = signal[t] + gamma * bootstrap[t] * next_values[t] - current_values[t]
gae[t]   = delta[t] + gamma * lam * carry[t] * gae[t+1]

advantage[t] = gae[t]
target[t]    = gae[t] + current_values[t]
```

| 情形 | bootstrap | 递推 |
|---|---|---|
| **terminated** | 0（不使用 `next_values[t]`） | 中断 |
| **truncated** | 用**本条** `next_values[t]` | 中断 |
| 非边界 | 用**本条** `next_values[t]` | 正常 |

## 5. 校验（全部显式失败）

- `signal` / `current_values` / `next_values`：一维、非空、全有限、长度均为 `T`；
- 三套 signal 长度一致；每头的 `current_values` / `next_values` 长度均为 `T`；
- `terminated` / `truncated`：一维、长度 `T`、dtype 必须为 `bool`、不得同时为真；
- `gamma ∈ [0,1]`、`lam ∈ [0,1]` 且有限；
- **长度 `T+1` 的旧 `values` 传入必须报错**（不得静默截断或兼容）。

### 10.3 最小反例（实测）

```python
signal         = [1.0, 1.0]
```

| | t=0 的 delta | t=0 的 target |
|---|---|---|
