## 4. 勘误内容

**原式（错误，保留原文）**：
`P_grid + pv_used + wind_used + discharge = P_idc + charge + curtail`

错误性质：把 **curtailment 计入需求侧**。代入弃电定义后等价于
`P_grid + 2·pv_used + 2·wind_used + … = P_idc + charge + pv + wind`，即**可再生被双重计数**；
在「可再生充足」时该式必然错误。

**正确式**：
```
P_grid + pv_used + wind_used + discharge = P_idc + charge      （供给 = 需求）
curtail = (pv − pv_used) + (wind − wind_used)                   （弃电 = 未消费的可再生）
```
与 `envs/idc_price_env.py` 的 M3.5 能量流、以及 M3.7a 的 form-1 恒等式一致。

**修复出处**：M4.3a1 提交 `057e152`（实现，同时修正主 LP 与 base-only 诊断）与 `08c036c`（测试锁定，含弃电定义断言与断言形式更正）。
