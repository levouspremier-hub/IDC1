## 5. 须登记的例外（预登记）

`tests/test_m44a_raw_projection.py` 的两处 `planning.solver` 引用是**防回归守卫**（断言 corrector 不使用旧路径），
不在本卡授权清单内，但 `planning/solver.py` 删除后会使其 `import planning.solver` 失败。
故须**适配**该守卫为「模块已不存在 + corrector 源码不含 `planning.solver`」的等价断言；**不改变其防护意图**。

## 6. probe 更新

`planning/probe.py`：删除 `build_milp` 导入与 `legacy_single_step_milp_*` 字段；
只报告现行 **H 步 LP / H 步 MIP / 两阶段 raw projection（corrector）** 的规模、整数变量数、状态、
阶段耗时、总耗时、预算与 timeout 数；**不得把 `tracemalloc` 膨胀后的吞吐当作真实训练吞吐结论**。

## 7. contract version 不提升的理由

本卡仅删除**仓库内部、从未接线的旧规划实现**，不改动动作空间（21 维）、
`contracts` 形状（contract-v5）、checkpoint schema 或可见窗口语义。
`build_milp` 从未被任何 checkpoint 序列化，也不构成契约的一部分 → **无需提升 contract version**。
