### 修正 1：raw baseline 与 wrapper 同场景

新增统一工厂 `make_scenario_env(scenario, horizon)`，**raw baseline 与 wrapper 共用**；

```
tight   scenario_config: access=18.000  (declared 18.0)  soc_init=0.25 horizon=24 | raw_env_step mean=0.00059 s
```

### 修正 2：结果分类（替换 `optimal_count`）

`classify_outcome(reason)` 三类互斥：

| reason | 分类 |
|---|---|
| `none`、`deadline_shortfall` | `executable_candidate` |
| `timeout` | `timeout` |
| `base_shortage`、`solver_failure`、`proposal_invalid`、**任何未知原因** | `non_timeout_failure` |

输出字段：`executable_candidate_count`、`timeout_count`、`non_timeout_failure_count`、
`failure_counts`（含 `timeout`/`base_shortage`/`solver_failure`/`proposal_invalid`/`unknown`）、
`zero_action_fallback_count`、`unsafe_failure_action_count`。**`optimal_count` 已移除。**
