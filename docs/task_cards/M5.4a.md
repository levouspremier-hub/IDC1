## 1. 缺陷（M5.3f 遗留）

`make train` 当前执行

```make
train:
	@test -f safe_rl_v2/train.py || { echo "模块未完成：…"; exit 1; }
	@uv run python safe_rl_v2/train.py
```

实测（`895394a`）：

```
$ make train
    from safe_rl_v2.buffer import RolloutBuffer
ModuleNotFoundError: No module named 'safe_rl_v2'
make: *** [train] Error 1
```

两个问题：

1. **入口形态错误**：直接执行包内文件不会把仓库根加入 `sys.path`，
   故 `safe_rl_v2/` 的相对导入全部失败。正确形态是 `python -m safe_rl_v2.train`。
2. **`safe_rl_v2/train.py` 没有 `__main__`**：即便修正路径也只会导入模块、什么都不做。
   而「什么都不做却退出 0」比报错更危险 —— 它会被误读为「训练已完成」。

## 2. 目标

提供一个**可执行但不冒充正式实验**的训练入口：

- 默认（不带明确参数）因 **M1.2 冻结真实数据未解除**而**明确失败**，
  **绝不**悄悄回退到合成数据；
- 仅在显式 `--synthetic-smoke` 下运行一次短 dry rollout，产物全程自我标注为
  `synthetic=true` / `dry_run_only=true`，且 `trained` / `performance_evaluated` /
  `convergence_claimed` 全为 `false`。

## 4. 禁止项

1. **不写 checkpoint**、**不实现 PPO ratio/clip/熵项**、**不启动正式训练**。
2. **不得**在真实数据缺失时回退到合成数据（哪怕只是「先跑起来」）。
3. **不得**把合成 dry-run 表述为正式训练、评估或论文结果。
4. **不得**让 `task_seed` / `server_seed` / `forecast_seed` 留为 `None`
   （既有 env 在任一为 `None` 时使用 `default_rng(None)` 熵源，跨进程不可复现）。
5. **不得**以「什么都不做 + 退出 0」冒充成功。
6. **不得**覆盖已有成功 run。

## 5. 文档纠正（要求 7）

`safe_rl_v2/train.py` 当前写着预检在「**任何** forward / backward / optimizer.step 之前」。
该表述**不准确**：`collect_rollout` 内部会调用 `policy.act(obs_t, generator=...)`，
而 `act` 会执行 `forward`（采样阶段的前向）。**修正为**：

> 预检发生在 **rollout 收集之后**、**任何训练更新阶段的 forward / backward /
> optimizer.step 之前**。

（预检**不**在采样前向之前；它保证的是「更新阶段零副作用」，不是「整轮零前向」。）

## 6. CLI 契约

```
python -m safe_rl_v2.train [--synthetic-smoke] [--steps N] [--seed S]
                           [--corrector {on,off}] [--corrector-time-limit-s F]
                           [--base-dir DIR] [--run-id ID]
                           [--task-seed N] [--server-seed N] [--forecast-seed N]
```

| 情形 | 行为 |
|---|---|
| 无 `--synthetic-smoke` | 调用 `scenario.build_scenario(..., synthetic=False)`；因缺 manifest 抛出
明确的 M1.2 阻塞错误；写 **failed** manifest 后退出非 0 |
| `--synthetic-smoke` | 跑一次短 dry rollout，写 **success** run |
| `--steps <= 0`、`--corrector-time-limit-s <= 0`、`--corrector on` 但缺 time limit | 明确失败（写 failed manifest） |
| `--corrector` 非 `on`/`off` | argparse 拒绝（非 0 退出） |

### 6.1 产物（`runs/<run_id>/`）

`policy_seed`、`corrector_on`、`corrector_time_limit_s`、`steps`、`code_revision`、
`scenario_type`。

`report.json` 必须记录：`synthetic=true`、`dry_run_only=true`、
`claims={trained:false, performance_evaluated:false, convergence_claimed:false}`。
