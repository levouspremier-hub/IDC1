## 3. 已发现的语义缺陷（改造前）

`_update_deadline_miss()` 在任务执行**之后**调用，因此「期限跨越的那一步正好完成」的任务（`finish_time = latest_finish_time + 1`）在该步末已是 `finished`，被 `status in [not_arrived, finished, failed]` 跳过，**漏记违约**；而分类器按 `finish_time > latest_finish_time` 判其 `overdue_completed`。

实证：seed=0/frac=0.1 时 `terminal_deadline_miss_count=7` 而 `overdue_backlog+overdue_completed=8`；漏记任务 `id=8 arr=7 dl=4 lft=11 fin=12`。

## 4. 边界定义（不改变，仅锁定）

- `finish_time <= latest_finish_time` → 按时完成；
- `finish_time > latest_finish_time` → 逾期完成；
- `latest_finish_time = arrival_time + deadline`。

本卡**只修正违约记录的漏记**使其与该边界一致，不改变边界本身。
