## 2. 禁止项

- 不运行 `make train` / 正式训练 / validation / test；不改 readiness。
- 不修改 `envs/`、物理 / 任务约束、冻结资产、PPO 训练语义。
- **不得**让 `service_qualified` 默认 `true`；**未判定 ≠ 达标**。
- **不得**把 `total_objective_cost` 标作 SGD（含罚项的混合目标诊断量）。
- **不得**把可再生**占比**命名为「利用率」。
- **不得**伪造五类方法比较：缺方法 / 未实现 → **「未评估」**，不填中性动作冒充。
- **不得**把缺失的原始量填 0 冒充测量；不可计算须显式标记。
- 旧 23 维 / 无版本 checkpoint 必须**明确拒绝**。
- **不得**把 `safe_rl_v2/ppo_two_batch.py` 的 two-batch 恢复格式
  （schema `m1.3g-f-c-e-two-batch-resume-v1`）当作评估输入 checkpoint 复用或改名。
- 不把受控短跑结果写成性能结论；候选阈值（95%/1%）**不因本卡冻结**。

## 6. 数据使用顺序（本卡重申）

受控短跑 checkpoint **不是**正式训练产物，**只用 train split**；
正式训练 checkpoint 审核通过后才进入 validation；最终 test 只按
`docs/M6_EVALUATION_PROTOCOL.md` 的预定协议运行一次。
