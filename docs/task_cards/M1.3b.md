## 3. canonical reader 契约

```python
load_singapore_2024_half_hour(raw_dir, source_manifest_path) -> pandas.DataFrame
```

返回表必须：**恰好 17,568 行**；按时间**严格递增**；**无重复、无缺失**；
时间轴覆盖 `2024-01-01 00:00` 至 `2024-12-31 23:30`；
时区固定 `Asia/Singapore`；**不得**用 naive timestamp 冒充带时区时间；
**不插值、不补缺失、不重复日、不读取未来值**；
任一 raw hash/bytes/schema/year/timezone 不匹配即 **fail closed**。

固定列与来源：

| 列 | 来源 | 规则 |
|---|---|---|
| `timestamp` | 半小时轴 | tz-aware `Asia/Singapore` |
| `price_sgd_per_kwh` | USEP `USEP ($/MWh)` | ×0.001；**允许负值**，只要求有限 |
| `system_load_mw` | SASEA `system_demand`（**唯一来源**） | 非负且有限；**不得**读 USEP 的 `DEMAND (MW)` |
| `national_igs_mwh_per_half_hour` | EMC `FACILITY TYPE=IGS` 的 `NET INJECTION (MWh)` | 保留 MWh/半小时；非负有限；名称/metadata 必须是 **national intermittent generation** |
| `temperature_deg_c` | ERA5 | 有限 |
| `wind_speed_10m_mps` | ERA5 | 非负有限；**不得**称为本地风电实测 |
| `ghi_w_per_m2` | ERA5 | 非负有限 |
| `weather_source_timestamp` | 映射规则决定 | tz-aware，保留**实际来源**时刻 |
| `weather_age_minutes` | 映射规则决定 | 只能为 `0` 或 `30` |

## 4. 小时天气 → 半小时的**冻结映射规则**

采用 **“latest source timestamp not later than target timestamp”**：

- 目标 `h:00` 使用天气 `h:00`（`weather_age_minutes = 0`）；
- 目标 `h:30` 仍使用天气 `h:00`（`weather_age_minutes = 30`）；
- 逐行必须满足 `weather_source_timestamp <= timestamp`；
- **禁止**用下一小时天气填充当前半小时；**禁止**线性插值；
  **禁止** centered resampling；**禁止** backfill。

该规则必须写入 **canonical manifest 与文档**，不能只藏在实现里。
报告中不得简称“普通 forward fill”而省略可见性边界。

## 5. 明确缺失语义

canonical 表**不得新增或伪造** `local_pv_kw`、`wind_generation_kw`、
`carbon_intensity`、`arrival`。canonical manifest 必须把它们记录为
**unavailable / not_materialized**，并写明：

- national IGS **不等于** IDC 本地 PV；
- ERA5 wind speed **不等于**风电发电量；
- 尚无冻结的半小时碳强度；
- arrival 尚未进入 M1.3 数据口径。

9. 重复时间戳失败；
10. NaN、inf、非法数值失败；
11. raw SHA 或 bytes 与冻结 manifest 不一致时失败；
12. 非 2024 年数据或错误时区失败；
13. canonical manifest 记录输入四个 SHA、输出 SHA、列单位与映射规则；
14. canonical manifest 明确记录四项 unavailable 字段；
