## 1. 目标

新增 `pyproject.toml`、`.python-version`、`uv.lock`，在 Python 3.12 arm64 下用 `uv sync --locked` 建出可复现环境；验证 torch / gymnasium / stable_baselines3 / scipy / pandapower 可导入，`scipy.optimize.milp`（HiGHS）能解二元互斥微例；记录 CPU/MPS backend。旧 `environment.yml` 保持原样。

## 2. 边界（允许修改的文件）

- 新增 `pyproject.toml`（Python 3.12，运行时依赖，CPU-only torch）
- 新增 `.python-version`（`3.12`）
- 新增 `uv.lock`（由 `uv lock` 生成）
- 新增 `docs/task_cards/M0.2.md`（本任务卡）

## 3. 禁止项

- 不修改 `environment.yml`（作为历史文件保留，不改写为 macOS 环境）。
- 不安装 CUDA / Windows 包（`torch` 走 PyPI 默认 arm64 轮子，无 CUDA index）。
- 不下载训练数据。
- 不改研究代码、`marl/`、`grid_model/` 主逻辑、`legacy/`、顶层 shim。
- 不把 MPS 当作确定性基准（CPU 为正式复核平台）。
