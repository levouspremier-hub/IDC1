# 任务卡 M4.1c：规划时域外生量展开

## 0. 元信息

| 字段 | 值 |
|---|---|
| 任务卡 | M4.1c |
| 标题 | 为 planning_horizon_steps 每步提供带来源标记的外生量规划输入 |
| 分支 | p5-eval-viz |
| 角色 | Agent |
| 开始基线 SHA | （M4.1b 补遗后 HEAD） |
| 状态 | 进行中 |

## 1. 目标

为 `planning_horizon_steps` 内**每一个时段**提供完整、带来源标记的外生量规划输入；可见窗口外只能使用明确的保守/持久化假设，**绝不读取未来真值**。

## 2. 边界（允许修改的文件）

- `contracts/models.py`、`contracts/validators.py`、`contracts/__init__.py`
- `planning/snapshot_adapter.py`
- `checkpointing/versioned.py`、`safe_rl_v2/buffer.py`
- 新增 `tests/test_m41c_planning_forecast_extension.py`
- 新增 `docs/task_cards/M4.1c.md`（本任务卡）
- 可修正 `SystemSnapshot` 的遗留 `_kw` 文档表述（仅文档）

## 3. 禁止项

- 不实现/修改 MILP、corrector、PPO；不改 `marl/`、`grid_model/`、`legacy/`；
- 不把规划假设伪装成真实未来预测；不从窗口外读取任何真值。

## 4. 窗口外规则（固定并文档化）

| 量 | 窗口外规则 |
|---|---|
| PV / wind | 保守设为 **0** |
| price / carbon / temperature | **最后可见值持久化** |
| arrival（任务到达） | 保守设为 **0**（未来具体任务不得凭真值进入） |
| base_idc_power | 按**持久化温度**重新计算 |

## 5. 契约

新增冻结契约 `PlanningExogenousForecast`：
`horizon_steps`、`price`、`pv`、`wind`、`temperature`、`carbon`、`arrival`、`base_idc_power`（长度均 == `horizon_steps`）、
`visible_mask`、`assumed_mask`（互补）、`extension_policy`（规则文本）。

`SystemSnapshot` 保留原 `forecast: ScenarioBundle`（长度 `forecast_cutoff`）作为**真实可见预测**；
新契约仅是**规划假设展开**。`planning_forecast.base_idc_power` 必须与 `base_idc_power_forecast_kw` 一致（validator 强制，防止静默分叉）。

## 6. 版本

`CONTRACT_VERSION_ID`: `contract-v4` → **`contract-v5`**；v1–v4、无版本、旧 payload 显式拒绝。

## 7. cutoff=0

`forecast_cutoff <= 0` 时**显式拒绝**构建滚动规划快照（抛 `ValueError`），不得读取 t 时刻真值填补。
