## 2. 禁止项

- 不改环境、规划器、训练链、契约或受保护目录。
- 不绕过访问控制、不对 EMC 做循环/批量抓取；EMC 年度包仅接受用户在官方网页手工下载的本地文件。
- 不用重复日、默认曲线或合成曲线填补全年；不把 NEMS `DEMAND` forecast 称为实际系统负荷，也不把 IGS 称为逐设施实测 PV。
- 不把小时天气无声明地当作半小时真值；仅冻结原始小时序列，半小时映射留给后续有卡的读取器。

## 3. 实现与验收

1. 本地核验器验证 2024 年 USEP、实际系统负荷、IGS、温度/GHI/风速的时间轴、单位、缺失和 SHA-256。
2. 写入机器可读 manifest，包含来源 URL、使用条款/许可证、下载日期、时区、原单位、文件 hash、字段语义、缺失/插补/禁用规则。
3. 用固定微型输入先写失败测试，覆盖：全年连续性、USEP 单位、实际负荷与 forecast 的语义隔离、天气小时粒度、manifest 不得声明插补。
4. 使用真实 Singapore-2024 原始文件运行 `--verify --write-manifest`；产物仅在 `data/raw/` 和 `data/manifest/`。
5. 运行 `uv run pytest tests/test_m12_singapore_data_freeze.py -q`、`uv run python scripts/fetch_singapore_data.py --verify ...`、`make check`、`git diff --check`。

## 4. 证据

- 测试文件与真实数据校验 JSON（不含任何原始行）。
- manifest 中的文件 SHA-256、行数、覆盖范围与下载日期。
- 记录 EMC 仅个人/非商业使用、禁止系统性自动采集；研究使用者须自行确认用途符合条款。
