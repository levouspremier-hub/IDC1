## 1. 缺陷（M5.4b 遗留）

M5.4b 把 blocker 的实测结果**硬编码**进测试常量 `CORRECTOR_ON_REPRO_BLOCKER["measured"]`
（形如 `{"budget_0.05_6cpu_hogs_4_procs": {"digests": ["8468db982fa6", "842b06d3bf97"], ...}}`）。
问题：

1. 那些 digest 是**当时的快速手测**，不是可重复运行的产物 —— 换机器、换 scipy 版本
   都无法复核，也无法证明它们对应哪次代码 revision；
2. 结论「corrector 开启不可复现」因此在仓库里表现为**断言常量**，而不是**测量结果**；
3. 没有任何机制防止把结论写成预设值（无论预设「必然一致」还是预设「必然不一致」）。

**本卡不预设任何结论**：由探针在独立进程中真实测量，结论由数据推导。

## 4. 探针设计

### 4.1 单次测量（独立进程）

真实 `IDCPriceEnv20D`，显式 `task_seed=0 / server_seed=0 / forecast_seed=300000`，
policy 权重用 `torch.random.fork_rng` + 固定 seed 构造，采样用显式 `torch.Generator`。

**语义 digest** 覆盖：`observation` / `next_observation` / `raw_action` / `exec_action` /
`old_raw_log_prob` / `reward` / `business_cost` / `carbon_cost` / `electricity_cost_sgd` /
`terminated` / `truncated` / `correction_reason` / `planner_backend` /
`stage_a_status` / `stage_b_status` / `stage_a_objective` / `stage_b_objective` /
`projection_offset` / `business_gap` / `deadline_shortfall_work`。

**只排除**三个纯墙钟字段：`correction_solve_time_s` / `stage_a_solve_time_s` /
`stage_b_solve_time_s`。

### 4.2 结论逻辑（**纯函数**，可被测试独立驱动）

```python
def decide(mode: str, digests: list[str]) -> dict:
    distinct = len(set(digests))
    reproducible = distinct == 1
    return {
        "mode": mode, "runs": len(digests), "distinct": distinct,
        "digests": list(digests),                    # **全部**保留，不挑不删
        "reproducible": reproducible,
        "blocked": not reproducible,
        "failure_classification": None if reproducible else (
            "corrector_nonreproducible" if mode == "on" else "corrector_off_nonreproducible"
        ),
        "conclusion": "reproducible" if reproducible else "blocked",
    }
```

- `distinct == 1` **才**允许 `reproducible=true`；
- `distinct > 1` **必须** `blocked=true` 且带 `failure_classification`；
- 结论**由测量推导**，探针源码中不得出现任何预设 digest 字面量。

### 4.3 模式

| 模式 | 预算 | 期望 |
|---|---|---|
| `off` | 无 | **必须**跨进程逐位一致（不一致即为探针/环境缺陷） |
| `on` | 明确、固定、**非恒超时**（`0.05` s） | 由测量决定：一致 → `reproducible`；不一致 → `blocked` |

### 4.4 产物（`runs/<id>/`）

`config.yaml` / `metrics.parquet` / `report.json` / `figures/` / `manifest.json`，其中：

- **config**：代码 revision、solver 证据（`scipy.optimize.milp` / HiGHS / scipy 版本 /
  `options={"time_limit": …}`）、三个 env seed、`horizon`、预算、模式、每模式进程数；
- **metrics**：每 (模式, 进程序号, digest) 一行；
- **report**：每模式的 digest 列表、`distinct`、`reproducible`、`blocked`、
  `failure_classification`，以及**总体结论**；并显式声明本探针**不代表训练结果**；
- **manifest**：`status` 与 `failure_classification` 跟随总体结论。
