## 3. 验收

先提交失败测试，证明基线允许覆盖已冻结 manifest、未核验本机 raw 文件与既有
manifest、错误宣称 USEP 已物化为 SGD/kWh，且未区分本地冻结/上游下载时间和 ERA5
网格替代语义。实现后：

1. 已有同规范 manifest 只读幂等；任意来源、语义、时间轴或 raw 指纹差异均拒绝。
2. `--verify` 在 manifest 存在时核验四份 raw 的 SHA-256、bytes、year、时区、行数和
   缺失规则。
3. price 保留原始单位，声明后续 reader 的目标单位/比例，绝不声称 M1.2 已物化转换。
4. 每源明确本地取得或冻结时间；无可证明上游下载时间时写 `unknown`。
5. 天气来源明确请求坐标、返回网格坐标和国家级 ERA5 替代关系，禁止作为 IDC 实测。

## 4. 证据与回滚

- 运行用户指定的两组 pytest、只读真实数据 `--verify`、`make check`、`git diff --check`。
- 原始文件 hash 在改造前后必须相同；只提交 manifest 与代码/文档/测试。
- 本卡全部提交按反序 `git revert`；不触及 M1.2a 历史提交。
