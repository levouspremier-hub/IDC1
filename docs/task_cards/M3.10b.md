## 4. 契约版本与 loader 归属（先确认）

- 本链的版本化 loader 是本仓库**自建**的 `checkpointing/versioned.py`，**不在受保护目录**；
- `marl/checkpointing/` 是旧 MARL 链的训练管理器，按项目红线**不编辑**，也不是本链 loader。
- 因此本卡可直接把 `CONTRACT_VERSION_ID` 提升到 `contract-v2`，并由自建 loader 拒绝旧版。
- 若后续发现本链另有位于受保护目录的 loader，必须记录 M2.4 blocker 并停止，不得声称旧 checkpoint 已受保护。
