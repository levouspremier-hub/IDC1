## 3. 核心目标（改前缺陷）

### 3.1 当前没有唯一来源，四个入口各自硬编码 0.05

```text
safe_rl_v2/train.py:299                        DEFAULT_CORRECTOR_TIME_LIMIT_S = 0.05
scripts/smoke_main_chain.py:47                 DEFAULT_CORRECTOR_TIME_LIMIT_S = 0.05
scripts/probe_rollout_deterministic.py:41      DEFAULT_CORRECTOR_TIME_LIMIT_S = 0.05
scripts/probe_corrector_repro.py:63            DEFAULT_CORRECTOR_TIME_LIMIT_S = 0.05
```

### 3.2 train 的 corrector-on 无预算路径当前**直接失败**

`safe_rl_v2/train.py:436-439`：`--corrector on` 且未给 `--corrector-time-limit-s`
时抛 `TrainEntryError`。M5.4i 要求该默认路径解析为生产默认 0.25。

### 3.3 没有 provenance 三字段

四个入口都没有 `production_corrector_time_limit_s` /
`effective_corrector_time_limit_s` / `corrector_time_limit_source`。

### 3.4 release gate 无法区分生产默认与 override

`evaluate_release_gate` 只看 `distinct`/`processes`/`steps`，
**无法阻止**把显式 0.05 override 的观测当作生产默认证据。

## 4. 实现要求

1. **唯一来源**：`planning/corrector.py` 定义
   `PRODUCTION_CORRECTOR_TIME_LIMIT_S = 0.25`；其余四个入口 `import` 它，
   不得各自定义 0.25。
2. **默认路径解析为 0.25**：synthetic train `--corrector on` 无预算、`make smoke`、
   `probe_rollout_deterministic.py`、`probe_corrector_repro.py`。
3. **显式 override 保真**：显式 `--corrector-time-limit-s 0.05` /
   `--corrector-time-limit 0.05` 必须实际用 0.05，绝不静默替换为 0.25。
4. **provenance 三字段**：config/report/manifest 记录
   `production_corrector_time_limit_s`、`effective_corrector_time_limit_s`、
   `corrector_time_limit_source`；source ∈ {`production_default`,
   `explicit_override`, `disabled`}，且**由「是否显式给出预算」决定**，
   不是由数值是否等于 0.25 决定。
5. **命令账本保真**：未传预算时 `manifest.command` **不得**伪造显式预算参数；
   显式传时必须包含该参数。
6. **release gate 只认生产默认**：`passed = evaluated and all_qualifying and not blocked`
   （M5.4h2 的 fail-closed 规则保留）。只有来源为 `production_default` 的观测才能进入
   gate；显式 override 观测进入独立的 `override_observations`，如实记录但**绝不**
   参与生产 release 判定。未测量 / 样本不足 / 不稳定一律 `manifest=failed`、`exit!=0`。
7. **Stage A/B 共享一个 0.25 s deadline**：用 runtime spy 证明（见 §6 验收）。
