## 1. 目标

删除单位误标的 `group_capacity_kw`（实际为 work capacity），改为唯一字段 `group_work_capacity`（work-units）；补齐规划输入的结构不变量校验；契约版本升至 `contract-v4`。**不实现/修改 MILP、corrector、PPO**。

## 2. 已发现的问题（改造前）

| 问题 | 现状 |
|---|---|
| 单位误标 | `group_capacity_kw` 名字带 `_kw`，实际存放 `env.model.C_server`（work-units） |
| 结构不变量缺失 | validator 未校验 `delta_t_hours>0`、`planning_horizon_steps>0`、`soc_max <= soc_capacity`、三个逐组向量长度一致、`power_approximation_note` 非空、任务 `remaining_work/max_rate >= 0` |

- `contracts/models.py`、`contracts/validators.py`、`contracts/__init__.py`
- `planning/snapshot_adapter.py`，以及 `planning/` 中直接读取旧字段的 `model.py`、`corrector.py`（**仅字段迁移，不改求解语义**）
- `checkpointing/versioned.py`、`safe_rl_v2/buffer.py`
- 新增 `tests/test_m41b_planning_contract_units.py`
- 新增 `docs/task_cards/M4.1b.md`（本任务卡）

## 4. 禁止项

- 不实现或修改 MILP/corrector/PPO 的语义；不改 `marl/`；
- **禁止保留同值双字段或兼容 alias**（避免未来静默误用）；
- 不改物理链、动作空间、reward。

## 5. 须登记的范围外修改（预登记）

`safe_rl/corrector.py` 直接读取 `snapshot.group_capacity_kw`，**不在本卡授权名单**；
若重命名而不更新它，仓库静态检查与运行会直接失败。故本卡**仅做同名字段迁移**（不改变任何语义），
并在验收记录中如实登记该例外。

`marl/` 继续为**受保护旧基线、与 contract-v4 新链不兼容**，不改动。
