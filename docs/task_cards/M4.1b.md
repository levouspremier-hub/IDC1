## 2. 已发现的问题（改造前）

| 问题 | 现状 |
|---|---|
| 单位误标 | `group_capacity_kw` 名字带 `_kw`，实际存放 `env.model.C_server`（work-units） |
| 结构不变量缺失 | validator 未校验 `delta_t_hours>0`、`planning_horizon_steps>0`、`soc_max <= soc_capacity`、三个逐组向量长度一致、`power_approximation_note` 非空、任务 `remaining_work/max_rate >= 0` |
