## 1. 缺陷（M5.3a 遗留）

M5.3a 的 `load_state_dict()` 校验了**类型与静态定义**（版本、聚合口径、约束集合、
单位、budget/lr/max、multiplier 范围、log 有限性与长度），但**没有校验状态内部的自洽性**：
它只要求每个字段「单独合法」，不要求「整体上能由 `update()` 产生」。
于是一批**形态合法但物理上不可能**的 contract-v7 payload 会被静默接受，
恢复出一组永远不会出现的乘子历史。

### 1.2 为什么这些状态不可能由 `update()` 产生

`update()` 是唯一改变这些字段的入口，且它的形态固定：

```python
candidate = state.multiplier + state.learning_rate * (estimates[name] - state.budget)
state.multiplier = float(min(max(candidate, 0.0), state.max_multiplier))
state.updates += 1
state.log.append(state.multiplier)
...
self._updates += 1
```

因此**恒等成立**的不变量：

| 不变量 | 理由 |
|---|---|
| `0 ≤ log[i] ≤ max_multiplier` | 写入 `log` 的值就是被 clamp 过的 `multiplier` |
| `log[-1] == multiplier`（`updates > 0` 时） | `append` 发生在赋值之后，且此后只有再调用 `update()` 才会改变 |
| `constraint.updates == 顶层 updates` | 两者在**同一次**调用中各加 1，且初值都是 0 |
| `len(log) == updates` | 每次调用恰好 append 一项（M5.3a 已校验） |
| `updates == 0` ⇒ `multiplier == 0 ∧ estimate == 0 ∧ log == []` | 构造后的初始状态；`estimate` 只在 `update()` 内被写 |

本卡把上述不变量变成 `load_state_dict()` 的**强制拒绝条件**。

| # | 条件 | 违反时 |

合法边界（`multiplier` 恰为 `0` 或 `max_multiplier`；`log` 恰含这两个值）
**必须继续被接受**。

### 9.4 contract-v7 未升迁的理由

`state_dict()` 的**序列化 schema 完全不变**（字段集与取值域都不变）；
本卡只是把「原本就无效的 v7 状态」从「静默接受」改为「显式拒绝」。
`test_state_dict_shape_is_unchanged` 与 `test_contract_version_is_still_v7` 固定了这一点。

若升到 `contract-v8`，会把**修复前落盘但恰好自洽**的 v7 状态一并作废——
那些状态是完全合法的、可继续训练的。那属于**过度**破坏，
且与「拒绝不可能状态」这一目标无关。

### 9.6 范围外修改登记

`tests/test_m53a_lagrangian_state.py::test_load_accepts_multiplier_exactly_at_bounds`
构造的边界状态**原本就不自洽**（只改 `multiplier` 未同步 `log[-1]`）——
正是本卡新规则要拒绝的形态。已让夹具自洽（同步改 `log[-1]`），
**断言与测试意图未改动**。这是「新规则必然使旧夹具失效」的直接后果；
同等的边界覆盖已由 `test_accepts_log_values_exactly_at_bounds` 以自洽形态保留。

### 9.7 额外回归：任何被接受的状态必须是不动点

`test_any_accepted_state_is_a_fixed_point_under_single_field_mutation` 对合法状态的
**每个叶子字段**做穷举单点变异（23 个变异值 × 全部字段），要求每个变异
**要么被明确拒绝，要么必须是 `state_dict()` 的不动点**。
这条不变量同时覆盖 M5.3a 的静态规则与本卡的自洽性规则：任何
「被接受但 `state_dict()` 与其不等」的状态都意味着仍存在未被拒绝的不可能状态。

另加：`load → state_dict → load` 幂等；多轮真实历史逐位往返；
对随机长度真实 `update()` 历史（含 0、大值、截断路径）不得误杀。
