## 1. 目标

`safe_rl_v2/models.py` 现有实现是 M5.4 阶段的**占位**：`compute_gae(costs, values, gamma, lam)`
**没有终端掩码**，把 rollout 末尾一律当作可 bootstrap，且对中间步的终止/截断一无所知。
这会把跨 episode 的优势传播进上一条 episode，并把截断步误当终止步。

本卡重建该模块，使三套 value target 显式区分三种情形，并把旧的**无掩码 API 移除**
（不得静默默认终止语义）。**本卡只做数学与测试，不接线、不训练。**

## 4. 数学语义（必须逐条测试）

设单条 rollout 长度 `T`，`values` 长度 `T+1`（`values[t]` 是 `obs[t]` 的 critic 估计，
`values[T]` 是**最后一步 `next_observation` 的 bootstrap 估计**），
`signal[t]` 为该头的逐步信号，`terminated[t]` / `truncated[t]` 为逐步布尔掩码。

反向递推（t = T-1 … 0）：

```
bootstrap_mask[t] = not terminated[t]              # 截断仍允许 bootstrap
carry_mask[t]     = not (terminated[t] or truncated[t])
delta[t]          = signal[t] + gamma * values[t+1] * bootstrap_mask[t] - values[t]
gae[t]            = delta[t] + gamma * lam * carry_mask[t] * gae[t+1]
advantage[t]      = gae[t]
target[t]         = gae[t] + values[t]
```

对应三种情形：

| 情形 | `bootstrap_mask` | `carry_mask` | 语义 |
|---|---|---|---|
| **terminated**（1） | 0 | 0 | bootstrap = 0，递推中断；`values[T]` 不参与计算 |
| **truncated**（2） | 1 | 0 | 允许用该步 `next_observation` 的 value bootstrap，**后续递推中断** |
| **非终止/截断**（3） | 1 | 1 | 正常 GAE，允许 bootstrap（rollout 因 `steps` 上限结束） |

`carry_mask` 的作用：`t+1` 属于**下一条 episode**（env 在终止/截断后自动 reset），
其优势**不得**沿时间反向传播进本条 episode。

## 5. 业务违规量的单位约定（M5.2a 起生效）

- 信号来源：环境 `info["sla_violation_count"]`（`envs/idc_price_env.py::_compute_sla_metrics`）。
- 语义：**每步活跃逾期 SLA 违规计数**。对每个 `arrival_time < horizon`、状态不在
  `not_arrived/finished/failed`、且 `remaining_work > 1e-6` 的任务，若
  `current_time > latest_finish_time` 则计 1。
- **不是唯一违约任务数**：同一任务在其持续逾期的**每一步**都会被重新计 1。
- 因此：rollout 内逐步求和 = 「违规任务·步」(task-steps overdue) 累计量，
  与 episode 级「唯一违约任务数」**不等价**，两者不得互相换算或顶替。
- **M5.3 预算约定**：拉格朗日预算必须按**同一单位**设定——
  若按本信号累计，预算单位为「违规任务·步 / episode」；
  不得与「唯一违约任务数」或电费（SGD）混算。
- 碳排放量单位独立：`carbon_emission`（kgCO2e）；电费 `electricity_cost`（SGD）
  **不参与**本卡任一 target。

## 6. 公开 API

```python
compute_signal_gae(signal, values, *, terminated, truncated, gamma=0.99, lam=0.95)
    -> (advantage, target)                      # 单头

compute_three_value_targets(rewards, business_violations, carbon_emissions, values,
                            *, terminated, truncated, gamma=0.99, lam=0.95)
    -> {"reward": (adv, tgt), "business": (adv, tgt), "carbon": (adv, tgt)}
```

- `terminated` / `truncated` 为**必填关键字参数，无默认值**；
  `values` 为 `{"reward": ..., "business": ..., "carbon": ...}`。
- 旧的 `compute_gae(costs, values, gamma, lam)` **移除**（连同无掩码调用路径）。

## 7. 严格校验（全部显式失败）

- `signal` / `rewards` / `business_violations` / `carbon_emissions`：一维、非空、全有限；
- `values`：一维、长度恰为 `T+1`、全有限；
- `terminated` / `truncated`：一维、长度恰为 `T`、**dtype 必须为 `bool`**
  （整数 0/1 数组一律拒绝）、不得同时为真；
- `gamma ∈ [0,1]`、`lam ∈ [0,1]` 且有限；
- 长度不匹配、非有限数、非法掩码 → 明确的 `ValueError` / `TypeError`。
