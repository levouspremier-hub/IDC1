## 8. 人工复审结论（2026-09-29）

**部分通过。** v5 切分、61 个 validation 日、92 个 test 日、512×4 训练 origin 规则与
来源校验**可保留**；调度与校验器骨架有效。以下四处缺口须返修：

1. **方法所需产物错配**：`m9_experiment_matrix_v1.json` 给**规则法**与**独立滚动优化**
   也列了「正式训练 run、512 批 × 3 seed、21 维 PPO checkpoint」为必需产物——两者
   **并不训练 PPO**。
2. **配对单位语义错误**：v1 写成 `(split, episode_start, training_seed)`；规则法与优化法
   **没有训练 seed**。必须区分**共享场景种子**与 PPO **训练种子**，不得把重复使用的
   基线结果计作三个独立样本。
3. **库存可比性缺失**：`evaluation.adapter.evaluate()` 不记录初末 SOC/储能量，也没有
   库存可比门禁 ⇒ 服务达标且物理无违规**仍不足以**声称「同等库存下成本更低」。
4. **训练 checkpoint → 评估输入的接线缺失**：两套 checkpoint 契约都已存在，但缺少从
   **同一份真实训练权重**导出、加载并由统一评估器重现的通路。

**返修卡：M9.2-R1。** 保留 `m9_experiment_matrix_v1.json` 作为历史冻结记录，
以 **v2** 修正并明确取代之。
