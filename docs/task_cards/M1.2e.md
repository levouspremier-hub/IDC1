## 2. M1.2d 勘误（本卡纠正）

1. **整合分支实际起点是 `04296db`，不是 `6c5ed50`。**
   M1.2d 写作时把起点记为当时的 HEAD `6c5ed50`；而 M1.2d 自身的开卡/证据/交接
   三个提交落地后才轮到 M1.2e，故真实起点是 `04296db`。
2. **只读 `git merge-tree` 只能证明「最终树」层面的冲突面**（两个冲突文件），
   **不能**承诺逐提交 cherry-pick 只发生两次冲突。同一文件可能在多个提交上重复冲突；
   实际冲突次数必须**逐个提交如实记录**，不得据 merge-tree 的结论跳过检查。
3. **不推荐方案 C 的理由需要纠正**：C **并非技术必然要求重新冻结 manifest**
   （可在保留既有 manifest 的前提下重写接线代码）。不推荐 C 的**正确理由**是
   它会**丢弃 20 个已有审计提交历史**，并带来**重复实现与重复验证的风险**。
