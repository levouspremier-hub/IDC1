## 1. 四处返修

1. **v2 方法产物**：规则法与独立滚动优化的必需产物改为**各自的冻结方法配置、
   可追溯运行记录与动作/求解来源**，**不要求**训练批次或 PPO checkpoint；
   三个 PPO 席位仍要求各自按新 21 维契约训练 + 已审核 checkpoint。
2. **v2 配对键**：`(split, episode_start, scenario_seed)`；预登记主场景 `scenario_seed=0`，
   同日期所有方法共享任务流 / 初始队列与 SOC / 外生驱动 / 预测；PPO 训练 seed `0/1/2`
   仅作**结果分层**；无训练 seed 的基线按同一场景**运行一次**，供三个 PPO seed 配对引用，
   **不计作三次独立基线运行**。
3. **库存记录与公平门禁**（`evaluation/` 层）：初末 SOC/kWh、容量、目标 SOC、现有终点容差、
   `terminal_soc_recovery_kwh`、尾段结算量；保留 `service_qualified` 原义，
   另给 `inventory_comparable` 与 `fair_cost_carbon_pair_eligible`。
4. **训练 checkpoint → 评估输入接线**：新增 train-only 导出/复现入口。
