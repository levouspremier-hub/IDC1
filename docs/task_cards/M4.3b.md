## 4. MIP 模型

对每个规划步 `k` 增加二元变量 `z[k] ∈ {0,1}`：

```
charge[k]    <= charge_max    * z[k]
discharge[k] <= discharge_max * (1 - z[k])
```

**`z[k]` 语义**：`z[k]=1` 表示第 k 步允许**充电**（放电被强制为 0）；`z[k]=0` 表示允许**放电**（充电被强制为 0）。因此 `charge[k]·discharge[k] = 0` 对每个 k 严格成立。

复用并保持已修正的物理平衡：

```
P_grid + pv_used + wind_used + discharge = P_idc + charge
curtail = (pv − pv_used) + (wind − wind_used)
```

其余 H 步约束全部保留：逐任务×组×时段分配、任务速率/剩余工作/组 work 容量、期限 slack、接入上限、SOC 动力学与上下界、充放功率上限、无反送电、单位分离。
