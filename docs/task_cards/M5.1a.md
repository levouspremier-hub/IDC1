## 1. 目标

重建 `safe_rl_v2` 的 rollout 记录契约，使其能作为后续 PPO / 断点恢复的**唯一训练样本格式**。
**本卡只做 buffer 数据契约与持久化校验**；不实现 PPO ratio/clip、GAE、actor loss、乘子更新或训练循环接线。

## 2. 命名偏离说明（须登记）

## 5. 硬要求

- **`old_raw_log_prob` 只能绑定 `raw_action`**；字段、序列化结果、代码中**均不得出现 `exec_log_prob`**。
- `add()` 时对数组做**防御性复制**；调用方随后修改输入数组或 `correction_info` **不得污染已存 transition**。
- **严格拒绝**：动作维度错误、观测维度前后不一致、非有限数值、缺失版本、
  顶层与 transition 版本不一致、未知旧版本。
- `from_dict()` **不得静默补默认字段**或接受旧 payload。
- 新增 `next_observation` / `terminated` / `truncated` 属已持久化 rollout schema 的**破坏性变更**：
  **`CONTRACT_VERSION_ID` 必须从 v5 升至 v6**，并更新所有受影响测试；**旧 v5 rollout/checkpoint 必须显式报错**。
- `correction_info` 必须**可安全深拷贝且可 JSON 序列化**；**不可存 torch tensor、numpy scalar 等隐式不可序列化对象**。
- **不改** env、planning、corrector wrapper、`safe_rl/train_safe_ppo.py`、`marl/`、`grid_model/`、`legacy/`。
- **不改** `safe_rl_v2/train.py` 的 PPO 数学。

## 6. 后续工作（如实登记）

`safe_rl_v2/train.py` 目前**不消费本 buffer**（其 `dry_run_update` 自行采集，未使用 `RolloutBuffer`）。
将其接到真实 raw/exec buffer 并实现 PPO ratio/clip、GAE、actor loss 与乘子更新，
属 **M5.1b** 的后续工作。**本卡不声称训练闭环已完成。**

## 7. 版本升迁理由

`next_observation`、`terminated`、`truncated` 是**新增的持久化字段**，改变了已落盘的 rollout schema：
旧 v5 payload 缺少这三个字段，静默接受会导致 bootstrap 目标与截断语义错误（例如把截断步当作终止步）。
故必须 **v5 → v6**，并使 v5 与非 v6 payload **显式报错**。
