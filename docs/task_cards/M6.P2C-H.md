# M6.P2C-H Windows宿主盘耗尽与WSL主机恢复

- 边界：本卡、超时/正式campaign账、runs/m6p2c_host_storage_repair_v1/；只读宿主Get-Volume/发行版注册信息/ext4错误与进程核对；Windows D盘独立控制脚本，用WSL2.7.12受支持的wsl --manage Ubuntu --move迁移发行版到D:\WSL\Ubuntu-IDC，shutdown后/迁移后启动前全VHD SHA/长度验签，再检查服务、真实宿主空间、可写性、文件可读、sealed assets验证及训练资格。不得删除用户Windows文件或原训练证据；此卡不改执行源码。
- 禁止项：不强制remount读写，不对挂载中的ext4运行fsck，不格式化/注销发行版、不清任务队列或训练SOC、不删失败job/数据、不因主机故障认定训练合格。若迁移后仍需离线文件系统修改，先准备实际备份/具体方案；不能无备份自动e2fsck -y。每次有证据的外部中断只采用新ID受控重投一次，不无限重试。
- 验收命令：SSH/Systemctl/boot_id；Windows Get-Volume与Lxss BasePath及VHD长度；停机SHA与迁移后启动前SHA完全相同；C/D均至少30GiB可用；ext4非emergency_ro、root下唯一probe写fsync读回hash、lscpu/dmesg可读；idc_remote资产校验/完整v10资格另依G卡，未完成不得正式启动。
- 证据：C盘2097152字节、D233123258368字节、原VHD145788764160字节，根/dev/sdd emergency_ro、7个ext4_journal_check_start错误、lscpu/dmesg/sudo I/O错误、重启boot_id；旧2job及新2job现场保留、实际无训练进程；迁移控制脚本/Windows日志/原新完整SHA与注册路径、空间/读写/服务证据、标准五类产物及receipt。
- 回滚点：502d9a4独立分支提交。迁移只搬运完整VHD不变其ext4内容；需要回迁时停机后用官方manage --move回原目录并验签，先确认C盘空间，原正式失败证据及Mac验签副本保留。不改paper-baseline。

开卡status/diff干净。用户确认主机恢复后继续；SSH虽恢复但WSL仅运行4分钟，两个旧任务因worker消失interrupted。受控新ID重投尚处setup即再次暴露宿主C满，根emergency_ro，两个新worker已消失；立即停止新增训练提交，先修复真实存储容量。Windows当前非管理员；官方manage --move为当前用户发行版迁移，若要求管理员或失败则保留日志报告，不绕过权限。
