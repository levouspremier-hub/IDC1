冻结来源保持原字节。正式库存路径覆盖当前时刻至真实 episode 终点全部剩余步数。
先求最小目标缺口，再将该终点电量条件同时固定于 Stage A/B；随后保留最小
raw→exec 偏移和经济/服务 tie-break。所有阶段共享原有 0.25 秒预算。

共同目标为既有 50% SOC，45%–55% 合格区间及公平配对终点电量差 ≤1e-6 kWh 不变。
预测中不可达、求解失败/超时、实际终点、实际与预测终点残差分别记录；未知可达性
使用 null，不能把超时写成不可达。没有重置 SOC、队列或放松任何物理约束。

现有单位奖励斜率为购电 `0.5/60 = 1/120 reward/SGD`，退化 `1/0.2 = 5`，
后者是前者 600 倍。终端罚项被修正器消除，不能增大该项作为返修。决定只修复
退化费的金额尺度，版本名 `common-sgd-degradation-v1`：

`r_degradation_new = -(reward_cost_weight / cost_ref) * degradation_cost_SGD`。

按既有形式，系数为 `w_deg_new = w_cost * degradation_ref / cost_ref = 1/600`
（约 0.0016666667）。公式读取实际环境的既有系数及冻结参考值，并写入奖励审计；
refs_v4 不变。wrapper 返回 `r_new = r_old - r_deg_old + r_deg_new`，其他奖励分项、
物理执行、终端惩罚、raw/log-prob 不改，不添加逐步 SOC 偏离惩罚。

共同金额尺度仅有两个上述配对算术总奖励转正；另外两个的碳排或任务时序/平滑项
仍产生负差。保留这些分项，不能宣称凡现金收益为正就必须总奖励为正，也不能把
算术重算当成 PPO 更新或学习成功。落实后须在最终服务/库存候选上重新跑 train-only
对照、三个新初始化 8 批短跑和真实写盘验签，未通过仍不启动长训。
