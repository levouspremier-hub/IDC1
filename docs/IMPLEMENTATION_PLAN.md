# 数据中心能源协同调度：可执行实施方案（重建版）

> 状态：计划文件；不代表已执行任何安装、代码改造、训练或数据下载。  
> 基线：`a90a06f` 的现有仓库；本文件之后的每个步骤必须从干净工作树开始。  
> 目标：在相同业务、物理和信息条件下，检验安全 PPO 加联合滚动修正对成本、购电归属碳排及后续可执行性的作用。  
> 首版边界：单数据中心、20 个服务器组、小时级、20 个计算动作加 1 个储能动作、无反送电、IEEE-14 仅离线验证。

## 1. 总纪律和完成定义

### 1.1 不可违反的规则

1. 不放松接入容量、SOC、充放电互斥或任务约束来制造“可行”。
2. 不清空队列、不重置 SOC、不跳过任务来通过测试或评估。
3. 测试和评估不得读取未来真值；预测数组必须带来源、生成时刻和可见窗口。
4. 归一化参考值只来自训练集或预定物理尺度，冻结后所有方法共享；不得按测试日重算。
5. `marl/`、`grid_model/` 主逻辑、`legacy/` 和顶层兼容 shim 保持不改。旧 MARL checkpoint 不进入新主链。
6. 新主链禁止接受旧 23 维动作或无版本 checkpoint；应明确报错，不能填零或截断兼容。
7. 修改 `envs/idc_price_env.py::step()` 前，先提交该卡的失败测试；实现后该测试必须转绿。
8. PPO buffer 永远保存 `a_raw` 与其 log-prob；`a_exec` 只记录在 transition/info，绝不覆盖原始概率记录。

### 1.2 两类实施者

| 角色 | 允许工作 | 不得自行决定 |
|---|---|---|
| **Agent** | 只读审计、纯新增脚手架、数据清单、测试夹具、确定性求解器原型、运行门禁、报告生成、性能探针。 | 业务优先级、任务分配规则、物理公式、约束松弛、评价口径、实验结论。 |
| **VSCode 协作** | 会改变仿真或研究语义的代码：M3、M5、M6 的核心接线，以及模型、奖励、观测、动作和评价定义。 | 绕过验收、修改红线、在未审 diff 时提交语义变更。 |

同一任务卡只由一方写核心文件；另一方只能审阅、补测试或处理明确分离的文件。每张卡完成后人工看 diff，再开始下一卡。

### 1.3 每张任务卡的统一证据

每张卡必须在实现前写入以下五项，缺任一项不得开工：

- **边界**：允许修改的文件和接口。
- **禁止项**：该卡不可改变的语义和红线。
- **验收命令**：实现前存在、失败原因明确；不得在实现后为转绿而削弱断言。
- **证据产物**：测试名、机器可读结果、运行命令和输出路径。
- **回滚点**：独立分支上的一个提交；失败时 revert 该提交，不带入后续卡。

### 1.4 分支、产物与总门禁

- 分支依次使用：`p0-bootstrap`、`p1-data-contracts`、`p2-physics/<card>`、`p3-corrector/<card>`、`p4-safeppo/<card>`、`p5-eval-viz`、`p6-experiments`。`main` 只合并人工确认过的卡。
- 每次可运行任务写入 `runs/<run_id>/config.yaml`、`metrics.parquet`、`report.json`、`figures/`、`manifest.json`；`manifest.json` 写代码 revision、依赖锁、数据 hash、场景 hash、种子、命令和失败状态。
- 每一阶段至少执行：静态检查、该阶段测试、契约版本检查、泄漏回归、恢复一致性（适用时）和性能探针。正式训练前还必须冻结数据、容量场景、服务标准、碳预算、归一化参考值和实验表。

## 2. 真实基线与依赖顺序

当前基线中，`envs/idc_price_env.py` 仍为 23 维动作：20 个服务器组强度、urgent、continuity、BESS；逐组建议在约第 570 行被加权压成标量，`_actual_loads_from_completed_work` 按计划比例回分实际负载，风电只记录未进能量平衡，`reset()` 每日重置任务与 SOC。该事实决定 M3 必须先于 M4 接线、M5、M6 和任何正式实验。

```text
M0 ─┬─ M1 ─ M2 ─ M3 ─ M4 wrapper ─ M5 ─ M6 ─ M7 ─ M9
    │                         │                    ▲
    └──────── M8（只读/离线） ┴────────────────────┘
```

M4 的纯算法模型可在 M3 期间独立原型，但不得接入训练或声称已保证环境安全，直到 M3 的真实执行—功耗链和失败处理均通过。
